# Агора Каталог V0

SEO-каталог поставщиков упаковки по Москве. Человек ищет в Яндексе «гофрокороба Москва»
→ попадает сюда → видит проверенные карточки поставщиков → оставляет заявку
→ её руками разбирает оператор.

Отдельный продукт-разведчик перед большой Агорой: проверяем, что на такой каталог
вообще идёт поисковый трафик и что из него получаются заявки.

**Не путать с четырьмя репозиториями основной Агоры**
(`agora-back`, `agora-admin`, `agora-leads`, `agora-tgbot`) — это независимый продукт.

## Устройство

- `packages/db` — Drizzle + PostgreSQL. Схема — единственный источник истины.
- `apps/api` — публичный API + операторская панель. Только московский VPS (152-ФЗ).
- `apps/web` — Next.js, публичный каталог. Хостинг — вопрос DNS, не архитектуры.

## Документы, в этом порядке

1. `CLAUDE.md` — правила и границы. Что нельзя и почему.
2. `docs/WORKFLOW.md` — как поднять окружение и как сдавать работу.
3. `docs/API.md` — контракт публичного API. Формы ответов зафиксированы.
4. `docs/tasks/` — карточки задач.

## Быстрый старт

```bash
scoop install postgresql
createdb agora_catalog_dev
echo 'DATABASE_URL=postgres://postgres@127.0.0.1:5432/agora_catalog_dev' > .env
npm install
npm run -w @agora/db push
```
